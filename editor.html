Kennedy Concession Menu Editor

Edit items and prices, preview the TV board, then download one updated menu-data.js file to replace on GitHub.

No database or monthly fee is required. The TV always reads the latest menu-data.js published in your GitHub repository.

To publish an update: download menu-data.js, upload that single file to the root of the GitHub concessions repository, and commit the change. GitHub Pages will refresh automatically.
