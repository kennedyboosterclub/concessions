Kennedy Concession Menu Editor

Change products, prices, descriptions and photos. Preview the TV board, then publish the changes directly to GitHub Pages.

Product photos are built into the menu data. Choose an image from your phone or computer; the editor automatically resizes/compresses it so you do not need to upload a separate image file to GitHub.

Board text

Publish to your TV

The editor can update menu-data.js in your kennedyboosterclub/concessions repository. GitHub requires a fine-grained personal access token with Contents: Read and write access to this repository. The token is only kept for this browser tab and is never written into the website files.

After publishing: GitHub Pages normally rebuilds automatically. The TV page is configured to request the latest menu data on each reload, so a Fire TV browser refresh will pick up the new menu instead of relying on an old cached copy.
