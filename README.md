# Kennedy Football Concessions Digital Menu

Files:
- `index.html` — TV menu for Fire TV / Silk Browser
- `editor.html` — simple menu editor

## Free GitHub Pages setup
1. Create a new public GitHub repository, for example `kennedy-concessions`.
2. Upload `index.html` and `editor.html` to the repository root.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then save.
6. GitHub will give you a URL similar to `https://YOURNAME.github.io/kennedy-concessions/`.
7. Open `/editor.html`, make changes, then click **Create TV link**.
8. Paste/bookmark that generated link in Amazon Silk on the Fire TV Stick.

## Important editor behavior
Because GitHub Pages is a free static website, it does not include a database. The editor can:
- save changes locally on the device you're editing from;
- export/import menu JSON;
- create a shareable TV URL containing the current menu configuration.

That shareable link is the easiest no-cost way to update the Fire TV without paying for a backend/database.
